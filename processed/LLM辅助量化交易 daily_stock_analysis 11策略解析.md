# LLM辅助量化交易 daily_stock_analysis 11策略解析

## 核心结论
> daily_stock_analysis 是一个以 LLM 为辅助、规则为核心的量化分析框架,采用数据-计算-AI-报告四层架构,内置 11 个覆盖趋势跟踪、形态识别、情绪周期等不同市况的策略,并配合 ReAct Agent 调度与策略路由机制。项目的核心定位是让 LLM 承担信息收集、汇总与口语化决策建议的参谋角色,仓位与风控由硬规则把控——LLM 不直接赚钱,只负责把结构化数据翻译成可读结论。

## 详细内容
## 项目概览

[[daily_stock_analysis]] 是 GitHub 上 31.8K star 的开源 LLM 股票分析项目,整体架构分为四层:

- **数据层**:通过 [[Tushare]] 抓取日线、实时行情、估值、筹码等字段
- **计算层**:用 Python 预计算 [[均线]]、乖离率、量比、趋势状态等指标
- **AI 层**:基于 [[DeepSeek]] 等大模型,结合 [[ReAct Agent]] 流程输出策略建议
- **报告层**:整合结论、舆情、风险与回测结果

实验标的是 A 股贵州茅台(600519.SH),结论支持「LLM 当前只能作为量化辅助,不能直接下单赚钱」这一观点。

## 数据层设计

数据层三大原则:多源降级 + 断点续传 + 前复权对齐。任一数据源故障自动切下一源;已抓交易日不重复请求;所有均线计算基于前复权价格以避免除权缺口产生的假信号。

核心字段包括:日线 OHLCV、涨跌幅、量比、换手率、PE/PB、60日涨跌幅、获利比例、平均成本、90% 筹码集中度等。

## Prompt 层关键规则

系统提示词遵循四条硬性约束:

1. **结论先行**:核心总结一句话,不超过 30 字
2. **分仓建议**:区分无持仓与有持仓两种情况
3. **精确价位**:止损、入场必须给出具体数字
4. **风险优先**:高严重度风险直接降级信号

舆情解析强制要求每条信息带具体日期,超出窗口或时间未知的新闻一律忽略;数据缺失时严禁编造,必须显式说明「数据缺失,无法判断」。

## 11 个核心策略

按适用市况整理如下。

### 趋势跟踪类(上涨市)

- **策略 1｜bull_trend 默认多头趋势**:MA5/MA10/MA20 多头排列 + MA20 斜率向上,优先「回踩不破」而非「高位追涨」,跌破 MA20 直接 -12 分。
- **策略 2｜ma_golden_cross 均线金叉**:MA5 上穿 MA10(3 日内)为主信号,MA10 上穿 MA20 为强信号,必须配合量能确认(金叉日 > 5日均量,量比 > 1.2),无量金叉视为假信号。
- **策略 3｜volume_breakout 放量突破**:收盘站上 20 日高点或前期平台顶部,量能 > 5日均量 2 倍,且次日收盘仍在突破位之上——用「确认日」过滤假突破。

### 回踩与反转类

- **策略 4｜shrink_pullback 缩量回踩**:上升趋势中回踩 MA5/MA10,回调期间成交量 < 5日均量 70%,是趋势交易性价比最高的入场点。
- **策略 5｜box_oscillation 箱体震荡**:在箱底(距支撑 ≤ 5%)买入,箱顶(距阻力 ≤ 5%)止盈,箱中观望;用「两日规则」过滤假突破。
- **策略 6｜bottom_volume 底部放量**:长期下跌(>15%)后突然放量(量比 > 3.0)+ 收阳 + 长下影线,属左侧交易信号,仓位不超过 2-3 成,警惕二次探底。

### 理论与形态类(高波动)

- **策略 7｜chan_theory 缠论**:核心是 [[背驰]] 判断——顶背驰卖出、底背驰买入;买点体系包含一买(下跌末中枢底背驰)、二买(离开中枢后回调不破中枢高点)、三买(中枢上沿突破)。
- **策略 8｜wave_theory 波浪理论**:5 浪推进 + 3 浪调整,第 3 浪「绝不是最短浪」是唯一硬约束;最佳买点是第 2 浪回调企稳(黄金坑),止损设第 1 浪起点。
- **策略 11｜one_yang_three_yin 一阳夹三阴**:大阳 → 缩量三阴(最低价不破大阳开盘、量比 < 0.8)→ 再阳突破第 1 日收盘价,本质是上升中继整理。

### 板块与情绪类

- **策略 9｜dragon_head 龙头策略**:识别板块领涨股,要求所在板块近 5-10 日涨幅居前、个股率先涨停、换手率 > 5%、量比 > 1.5;龙头可放宽乖离率至 7%,板块熄火立即离场。
- **策略 10｜emotion_cycle 情绪周期**:用换手率做情绪标尺——< 0.5%/日为冷淡底部,> 10% 为极度狂热;情绪底部买入、情绪顶部减仓,是最接近「逆向投资」的策略。

## Agent 与路由

[[ReAct Agent]] 采用「LLM 规划 → 执行工具 → 结果返回 → 决策下一步」循环,内嵌四阶段工作流:先凑齐数据 → 数据分析 → 策略匹配 → 输出结论。

策略路由支持两层逻辑:用户显式指定优先;否则按市场状态自动推断(ma_alignment + trend_score → trending_up/down/sideways),匹配对应策略集,无匹配则兜底为默认激活集。

## 持仓与回测

**持仓风险分析完全由规则驱动**,不依赖 LLM 判断:单票集中度 35%、行业集中度 35%、最大回撤 15%、止损距离 10%、观察区 8%;LLM 仅负责把规则结果翻译成口语化建议。

**回测机制**通过关键词+否定词模式从 operation_advice 字段推断方向意图(bull/bear/hold/wait/neutral),与后续 5 日实际走势对比,输出模拟收益率与中性带宽触发情况,用于追踪 LLM 分析的有效性。

## 核心观点

LLM 在量化交易中的合理角色是信息收集、汇总与决策辅助,不是直接赚钱的执行者;真正决定盈亏的仍是硬规则、仓位管理与策略本身的胜率优势。
