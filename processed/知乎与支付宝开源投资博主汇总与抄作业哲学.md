# 知乎与支付宝开源投资博主汇总与抄作业哲学

## 核心结论
> 开源投资博主通过公开实盘与逻辑推演降低散户学习成本，但真正的核心在于「选对人」而非「抄作业」——选博主与开发新算法时挑选 baseline 同理，先跑通 demo 再深入研究每一行代码。MR Dang、寒武纪、贾志等代表不同风格的开源投资流派，共同点是重视 [[安全边际]] 与逆周期买入。

## 详细内容
## 开源投资博主生态

在 [[开源]] 文化语境下，[[开源投资博主]] 指在知乎、雪球、支付宝等公开平台持续披露投资逻辑、选股理由乃至 [[开实盘]] 操作的投资者。这与传统的荐股「喊单」不同，更接近于 [[程序员]] 阅读 paper 与扒 GitHub 方案——读者可以追溯、验证乃至复现其投资框架。

## 主要博主与风格

- **MR Dang**：被作者称为目前最强的开源投资博主，文章有理有据、胜率高。但出于合规考虑，其表达常打哑谜，仓位比例未公开，且部分推荐标的位置偏高，跟买存在心理压力。
- **寒武纪**：选股领域与 Dang 相近，鳄鱼式策略更适合非专业普通人，但需较强耐心。价值判断略弱于 Dang，胜在低位买入、旱则资舟水则资车、遵循 [[逆周期]] 原则。作者曾跟买 [[中钢国际]]、[[齐翔腾达]]、[[恒邦股份]]，因缺乏信心微亏离场后卖飞。
- **观察者**：25 年观点命中率高，曾在白银 60 多美元时做空白银（现已涨至 100 多）。但评论区指出其会删除预测错误的记录。目前已退网自闭。
- **贾志**（支付宝）：风格极其稳定，耐心强、能空仓很久，买入标的均处低位，[[安全边际]] 高。最大特色是 **公开实盘**——多少钱、多少仓位、怎么操作全部透明，这让小白跟随时几乎不需要动脑筋。后续转向主动基金，已不可再跟。

## 抄作业的工程类比

作者作为程序员，将投资学习类比为工程实践，核心观点有三：

1. **信息过载，价值内容淹没在噪声中**：GitHub、知乎、雪球上开源内容极多，真正有价值的反而难以识别。
2. **不懂时，先选人再研究**：与开发新算法一样，需要从众多方案中先选定一个真正有效的 [[baseline]]，跑通 demo 后才有动力逐行阅读。
3. **专业边界意识**：人有自己的主业，不可能精通所有领域。承认这一点，才能在 [[择人]] 上投入足够精力。

## 小结

开源投资的精髓不在于「免费的午餐」，而在于把决策链路变得可追溯、可验证。读者真正要学会的不是某一笔交易，而是 **如何挑人** 与 **如何低位买入后敢于耐心持有**。
