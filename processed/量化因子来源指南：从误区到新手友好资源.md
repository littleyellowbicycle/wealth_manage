# 量化因子来源指南：从误区到新手友好资源

## 核心结论
> 因子研究的核心在于信息维度而非数量堆叠，盲目堆砌因子会拖累模型稳定性；新手应优先深耕量价因子，并以 Quantpedia、Quantocracy、Factors Directory 等专业资源作为因子灵感与构造逻辑的起点，再回到自有数据上复现验证。

## 核心结论

因子研究的核心在于信息维度而非数量堆叠，盲目堆砌因子会拖累模型稳定性；新手应优先深耕[[量价因子]]，并以 [[Quantpedia]]、[[Quantocracy]]、[[Factors Directory]] 等专业资源作为因子灵感与构造逻辑的起点，再回到自有数据上复现验证。

## 常见误区：因子重质地不重量

很多入门量化的朋友会陷入三类困境：直接套用现成因子赚不到钱、自创因子一回测就崩、因子越攒越多但模型越来越不稳定。问题根源往往在于把因子多等同于模型强。

把因子想象成二维平面上的点，真正重要的不是点的数量，而是这些点能否铺满空间。好因子的标准是它代表了一个全新的信息维度，而不仅仅是一个新奇的变换形式。所以建立因子库的第一原则是：[[因子重质地，不重堆量]]。

## 三大因子来源

从信息来源看，市面上的因子本质上都属于以下三类：

1. **量价因子**：基于价格、成交量、K线形态、订单流等市场微观结构构建，是数据获取最容易、逻辑最贴近市场行为、可塑性最强的一类，是新手的主战场。细分方向包括[[动量]]/反转、波动率、量价结构、K线形态、高频订单流等。
2. **基本面因子**：包括财务指标、期货期限结构、宏观经济数据等。这类因子更新频率低、获取成本高，更适合作为大方向判断的参考，而非直接进入高频或短周期模型。
3. **另类因子**：包括舆情、搜索指数、卫星图像、物流、社交媒体数据等。信息含量丰富但重资产特征明显，对新手而言成本与收益不匹配，建议积累到一定阶段后再考虑。

## 新手友好的五大因子来源

### 1. Quantpedia——学术因子索引库
- 链接：quantpedia.com
- 定位：把学术论文中证明有效的策略与因子逻辑抽象出来，按策略类型分类整理。
- 用法：使用 Screener 按类型过滤策略；顺着论文链接追溯因子构造的原始逻辑；把网站当作因子构造灵感库与学术逻辑索引库，而非直接套用的因子数据库。

### 2. Quantocracy——海外量化文章聚合站
- 链接：quantocracy.com
- 定位：聚合全球量化博客与研究者的优质文章，覆盖大量因子构造与回测思路。
- 用法：网站本身不提供站内搜索，可用 site:quantocracy.com 关键词 通过 Google 检索；很多文章附带 R/Python 实现代码，对英语阅读能力尚可的新手非常友好。

### 3. Factors Directory——因子百科
- 链接：factors.directory/zh
- 定位：整理 500+ 可用量化交易因子的定义、公式与分类。
- 用法：按类别筛选目标因子，理解每个因子的信息来源和构造逻辑，再按公式在自有数据上复现。特别适合新手学习因子长什么样。

### 4. 时到量化因子浏览器——可视化因子表现
- 链接：shidaotec.com/factorlib.html
- 定位：按筛选条件（股票池、调仓周期等）查看因子的历史表现与统计指标。
- 用法：快速横向对比不同因子的回测效果，定位值得深入复现的对象。数据深度有限，但上手成本低。

### 5. BigQuant 社区——因子数据源与研报
- 链接：bigquant.com/data/home
- 定位：提供量价、基本面等多类因子数据源，并附带社区案例与策略报告。
- 用法：按分类下载数据，作为因子构造与测试的原始输入，特别适合实盘级数据复现。

## 高效使用资源的小技巧

拿到一个因子，先不要急着丢进模型回测，而是先问自己三件事：

1. 它反映的市场现象是什么？
2. 这个现象是否具有可验证性（历史与未来是否一致）？
3. 自有的数据频率、清洗标准是否与原始研究一致？

只有逻辑层面的问题回答清楚，组合与优化才有意义。[[因子构造]]的过程，本质上是对市场行为的建模，而不是对数字的拟合。

## 总结路线图

新手建立因子库的推荐路径：先吃透[[量价因子]]的基础构造，再借助 [[Quantpedia]] / [[Quantocracy]] 拓展思路、利用 [[Factors Directory]] 学习标准化定义，最后用 [[BigQuant]] 或自建数据完成回测验证。在这一过程中，始终以信息维度作为筛选标准，避开以量取胜的陷阱。
