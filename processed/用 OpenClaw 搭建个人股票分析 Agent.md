# 用 OpenClaw 搭建个人股票分析 Agent

## 核心结论
> 借助 OpenClaw 这类 Agent 框架，个人无需编程或量化背景，只需一台服务器、一个 Finnhub API Key，就能在 10 分钟内搭建出能自动抓取实时行情并产出盘前选股报告的自动化系统。真正的价值不在于选出的 5 支股票本身，而在于把"盯盘"这件事从人工操作升级为可调度、可学习的 [[Agent 工作流]]。

## 详细内容
过去几年，[[量化交易]] 机构和[[高频基金]]凭借数据与系统优势把普通投资者远远甩在身后；而以 [[OpenClaw]] 为代表的 Agent 框架，正在把这种能力下放到个人手中。本文记录一条完整的搭建路径：服务器部署 → Agent 人设配置 → 实时数据接入 → QQ 机器人打通 → 自动输出[[盘前报告]]。

## 一、配置盘前交易 Agent

在 OpenClaw 中执行 `openclaw tui` 进入交互式对话框，通过自然语言指令让其创建一个"股票日报分析 Agent"。关键是把精心设计的 [[Agent 人设]] prompt 喂给框架，由它生成一个名为 Marcus 的交易 Agent，负责每日盘前的[[选股]]逻辑。完整 prompt 可通过关注公众号"算法一只狗"并回复"股票prompt"获取。

这一步的本质是：用一段结构化 prompt 把交易经验沉淀为可复用的[[角色设定]]，让 Agent 在每天固定时间调用同一套分析流程。

## 二、接入 Finnhub 实时行情数据

仅有 Agent 人设还不够，必须让它能拿到实时股价。流程如下：

1. 前往 [[Finnhub]] 官网（finnhub.io）注册并申请免费的 API Key；
2. 把 Key 提供给 OpenClaw，让框架自动接入 Finnhub 的常用行情接口；
3. 同时让该 Agent 接入浏览器搜索能力，以便结合新闻做技术面与消息面分析。
4. 测试调用：若能正常返回股票数据，即接入成功。

这一步对应 [[实时行情 API]] 的[[工具调用（Tool Use）]]能力——Agent 不再是"聊天机器人"，而是能够主动拉取外部数据的执行体。

## 三、生成盘前报告

打通数据后，向 Agent 下达"输出一份盘前报告"的指令，即可得到一份包含当日候选 5 支潜力股的[[盘前报告]]。报告融合实时行情、新闻舆情与技术面信号，比人工盯盘更稳定。

## 四、闭环与延伸

完整链路为：服务器部署 → Agent 人设 → Finnhub 实时数据 → QQ 机器人推送 → 自动生成盘前报告。整个系统具备三个长期价值：

- **定时自动化**：每天固定时间输出报告，无需手动触发；
- **数据闭环**：自动抓取实时行情并结合新闻综合判断；
- **偏好学习**：Agent 可基于用户反馈持续迭代筛选标准。

从"聊天机器人"进化为"交易助理系统"，核心是把分散的人工动作打包成一个可调度的 [[Agent 工作流]]——这才是个人投资者与机构之间差距被快速抹平的根本原因。
