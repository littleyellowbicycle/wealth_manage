# 有色化工资源股配置计划与布林线交易纪律

## 核心结论
> 作者将有色化工[[资源股]]视为穿越牛熊的[[镇仓石]]，以[[布林线]]为核心设计了一套从选股、建仓、做T到止盈的全流程交易纪律。当前板块情绪高涨且部分标的已大幅上涨，不建议急于开仓，应耐心等待价格回踩布林线中轨再分批建仓。该方案的核心不在于具体标的选择，而在于通过规范化的纪律执行来规避追高接飞刀的常见错误。

## 详细内容
## 配置思路

在整轮行情中，分散配置足够的[[资源股]]个股可以作为账户的[[镇仓石]]。[[周期股]]一般不会急涨急跌，拉长均线来看一直在走趋势，可以沿着[[布林线]][[滚仓做T]]，分散到不同板块和个股以平摊风险，避免单一个股的业绩不及预期或其他黑天鹅。

由于去年[[年金银]]已经上涨了不小幅度，部分个股已经翻倍甚至3-5倍，作者选择避开高位品种，重点关注以下四个方向：

- **锡**：[[锡业股份]]
- **磷**：[[云天化]]
- **钾**：[[亚钾国际]] + [[盐湖股份]]
- **铝**：[[宏创控股]]

## 交易纪律

### 1. 趋势票必须规范化操作

开仓/减仓/做T/止盈都应有明确纪律，而非主观判断"跌得够多"或"赚得够多"。大跌加仓容易[[接飞刀]]，大涨清仓又可能[[卖飞]]。具体采用五日线、十日线还是[[布林线]]并不重要，**重要的是规范化每一笔操作，遵循同一套纪律**。从[[大数定律]]的角度看，只要纪律没有原则性谬误，长期执行下来收益曲线必然稳健。

### 2. 资源股更适合布林线纪律

大多数资源股都沿着[[布林线]]趋势上行，当市场风格不在有色化工时，它们往往小涨小跌磨时间。以五日线/十日线做标准会出现横盘四天被错误止损的情况，而沿着[[布林线]][[滚仓做T]]更为稳妥，几乎适用于所有资源股。

### 3. 耐心等待倒车接人

资本市场从来不缺少机会，缺少的只有耐心。任何板块在[[主升段]]都会让人觉得涨得太快、再不买就来不及，但无论一致性多强，一段难以置信的上涨后基本都会回到一个让人觉得"不可能回到"的位置。**上涨时不要追高，踏空只是少赚，追高套住才是真亏**。

### 4. 布林线三档仓位方案

观察发现，大多数资源股都在[[布林线]]上轨和中轨间运行，基本面无问题的前提下跌至下轨反而是加仓良机。具体方案：

| 价位 | 操作 |
| --- | --- |
| 布林线上轨 | 减仓做T |
| 布林线中轨 | 开仓/接回 |
| 布林线下轨 | 加仓 |

## 选股逻辑与仓位配比

作者风偏较低，以小仓位做超短获取情绪价值，底仓则严格遵循"看不懂的不做、制定的纪律执行、犹豫的时候减仓、需要抉择就清仓"的原则。

- **锡 + 铝**：参考 Dang 老师的判断，看好锡故按3:1配置[[锡业股份]]与[[宏创控股]]
- **钾**（双标的）：因已重仓锂矿、电解液、电池ETF，需平衡钾的占比；[[盐湖股份]]常跟锂矿联动，全部配置会让仓位[[含锂量]]超标，故[[亚钾国际]]与[[盐湖股份]]按1:1配置
- **磷**：[[云天化]]作为唯一标的，份额给到2
- **补仓资金**：预留2份额用于[[布林线]]下轨补仓

| 规划标的 | 份额占比 | 建仓条件 |
| --- | --- | --- |
| 锡业股份 | 3 | 布林线中轨 |
| 宏创控股 | 1 | 布林线中轨 |
| 亚钾国际 | 1 | 布林线中轨 |
| 盐湖股份 | 1 | 布林线中轨 |
| 云天化 | 2 | 布林线中轨 |
| 补仓资金 | 2 | 布林线下轨 |

## 操作铁律（每日复盘提醒）

1. 分配账户1的**四成**作为资源股仓位
2. 沿布林线做波段[[滚仓]]，**卖飞的仓位不接回**，只拿剩余底仓继续按纪律做波段
3. 浮盈30cm后减一半，50cm后本金清仓只留利润；出现**破十日线3日不收回/单日放出天量/筑顶滞涨**任一信号即离场
4. 布林线下轨补原仓位的50%

## 当前判断

最近有色化工板块情绪高涨，不适合开仓。回调总会回踩布林线中轨，假设此处开启主升，最多也就是踏空；而踏空资源股还有机构票板块等待四月行情，不用着急建仓，**被套住会严重影响心态，纪律远比仓位更重要**。
