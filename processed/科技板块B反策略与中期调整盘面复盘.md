# 科技板块B反策略与中期调整盘面复盘

## 核心结论
> 大盘经历两根大阴线后空间基本到位、科创50还需补跌，预计周一早盘或周二早盘探底回升开启B反。操作上聚焦已跌至二十日线的科技细分与宽基指数（中证500>中证1000>中证2000），按个股分批低吸、B反次日午盘或尾盘出场，C浪杀跌再接回底仓。需注意B反并非100%盈利，遇弱反抽（如2024.11.19、2025.3.18）应严格止损。

## 详细内容
## 一、当前持仓与调仓

目前 4 成仓，结构为 25% [[电解液]] + 15% 底仓（[[封测]]、[[机器人]]、电源）。原锂矿：电解液 = 2:1，本周将一半锂矿切到电解液，形成锂矿：电解液1：电解液2 = 1:1:1 的均衡结构。

**长线仓与活动仓分离**：
- 长线仓锁仓不动，看的是供需逻辑
- 活动仓做[[趋势跟随]]，趋势坏就切——本周反抽五日线时已清掉锂矿
- [[电解液]]仍看好，但主动收缩锂电线仓位，另一只出掉

**尾盘抄底未执行**：担忧周末利好导致周一[[跳空高开]]，加上判断科技和指数节奏不同步，最终放弃先手建仓。

## 二、盘面分析

### 1. 指数层面

基于历史回测，确立以下前提：
- **节奏**：[[中期调整]]一般是两长一短，不会连续杀三根大阴线；若出现三连阴，意味着未止跌，第三/四天通常探底回升。
- **频次**：一轮趋势行情至少经历两次以上[[中期调整]]，且越往后越剧烈，前期调整可能在第三根阴线即结束。
- **结构**：调整走[[ABC浪]]。B反浪的开启方式决定其持续性：
  - 以**探底回升**开启：可延续约一天半，第二天还有分化上攻
  - 以**跳空高开**开启：早盘回落后可涨到收盘，若直接上攻则当日可能回落
- **弱反抽案例**：2024.11.19 与 2025.3.18，B反弱后C浪杀出新低

**判断指数低点在周一早盘或周二早盘**的四个依据：
- **空间**：[[二十日线]]已到，再低开基本到位
- **时间**：周一开B反偏早，若低开杀跌 30–60 分钟则可能到位；竞价高开则放弃
- **共振**：[[科创50]] 还需一根大阴线，但大盘空间已到，二者存在冲突，可能演化路径为：周一权重护盘 + 科技杀跌收小阴线 → 周二早盘高开回落再拉起
- **情绪**：[[RSI]] 约 40（指数已到，科创50 不够）、融资盘未明显下降、[[恐贪指数]]尚未触底

**结论**：大盘空间基本到位、时间差点火候；科创50 还不到位。

### 2. 科技板块

**总体原则**：科技不同细分都要去[[二十日线]]集结。十日线以下分批建仓；周一若低开再下挫即开始买入。

各细分判断：
- **旗帜股**：再杀一根大阴线到二十日线最完美
- **[[CPU]]**：走得最好的细分，情绪龙头接近二连板；第三根不能再杀，要停在二十日线上并缩量
- **[[AI硬件]]（光模块、PCB）**：独立走势，不适用二十日线法则；周四抗跌、周五补跌，下跌一步到位最好
- **[[存储]]**：仍有抵抗，韩国同行熔断情况下仍只有部分个股主动调整；周一补跌最佳
- **中位（[[封测]]、服务器、AIDC、晶圆厂）**：都在十日线与二十日线之间，一个低开即到位
- **[[半导体设备]]**：周五拉近 20cm 大阳线，高位回踩需两日，与其他细分不同步，是最不理解的走势
- **[[机器人]]**：本轮是大科技分歧下的低位补涨，与消息面无关；A浪调整不深，最多还剩 2 个交易日，加仓需等 C 浪同步杀跌
- **[[ETF]]**：成分股分散（存储、设备、CPU、晶圆厂），不适用单一细分结论；这也是科创50 需要普跌才能触底的原因

## 三、应对策略

| 情景 | 应对 |
|---|---|
| 周一低开 + 下挫 | 分批低吸，最差可平出；急跌回V则当日开启反弹，单边杀跌则次日探底回升 |
| 周一低开 + 拉升 | 已到二十日线的细分先建仓买套，未到位的观望 |
| 平开 / 高开 + 拉升 | 等回落 |

**操作纪律**：
1. 不一把梭哈，按个股按线建仓
2. 做好止损，B反第二天午盘/尾盘出掉，最多留底仓，C 浪再接回
3. **重点方向**：位置合适的细分 + [[宽基指数]]
4. 反弹优先级：**[[中证500]] > [[中证1000]] > 中证2000**（近期杀的是大票，宽基保证收益落袋）
