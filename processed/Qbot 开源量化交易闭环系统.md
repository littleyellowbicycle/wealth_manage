# Qbot 开源量化交易闭环系统

## 核心结论
> Qbot 是一个集成多种量化工具的开源交易系统，覆盖选股、选基金、策略分析与回测、模拟交易到消息通知的完整闭环，支持股票、基金、期货和加密货币多市场。项目曾冲上 GitHub Trending 前五，社区反馈良好，但仍处于持续优化阶段，架构尚有精简空间。

## 详细内容
## 项目概览

[[Qbot]] 是由 UFund-Me 团队开源的[[量化交易]]系统，项目地址为 [UFund-Me/Qbot](https://github.com/UFund-Me/Qbot)。它定位于打造从策略研发到模拟交易的完整闭环，面向个人投资者与量化爱好者。

## 技术栈与功能集成

Qbot 综合封装了多个主流[[量化金融]]工具库，包括：

- [[tushare]]：金融数据接口，提供股票、基金等行情数据
- [[backtrade]]：经典的回测框架，用于策略验证
- [[easytrade]]：交易执行层，连接模拟与实盘接口
- [[qlib]]：由微软开源的 AI 量化投资平台，支撑因子分析与机器学习策略

基于以上组件，Qbot 提供了以下核心能力：

1. **选股与选基金**：基于多因子模型进行标的筛选
2. **策略分析与回测**：在历史数据上验证策略有效性
3. **模拟交易**：本地可一键启动 `python main.py` 运行整套流程
4. **消息通知**：支持邮件和飞书推送交易信号与日报
5. **可视化界面**：提供 Web 端与移动端操作面板

## 覆盖市场

Qbot 对以下市场均有支持：

- A 股股票
- 公募基金
- 期货
- 虚拟货币（加密货币）

## 当前状态与社区反馈

项目在上线初期曾连续多日冲上 [[GitHub Trending]] 榜单前五，社区反馈整体积极。但作者也承认当前架构仍较为繁琐，正在持续优化中。后续计划在知乎与知识星球同步版本更新，并逐步分享更详细的策略原理与实现细节。
