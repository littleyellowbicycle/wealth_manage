# PB-ROE框架复现：基于招商量化精选的GARP策略拆解

## 核心结论
> 通过复现招商基金王平的PB-ROE选股框架，验证了GARP策略在A股的有效性——回测13年年化收益40.8%，2022年大盘下跌近20%时仍取得31.8%正收益。该策略本质是价值与成长的融合：在PB估值稳定的行业中筛选ROE成长性强的中小盘股票，并保持持仓高度分散以控制风险。

## 策略背景与基金经理介绍

区分投资高手与伪专家的关键，是将其交易方法放到历史数据中检验。本文以[[招商基金]]基金经理[[王平]]为例，进行策略复现。王平2006年入行，从数量分析师起步，2010年6月开始管理基金，证券从业16年，是国内老牌[[公募量化基金]]的代表性人物。其代表作是[[招商量化精选]]（A类001917），自2016年3月成立至今累计收益126.22%，大幅跑赢同期[[沪深300]]指数的30.03%。

## 核心框架：PB-ROE

王平策略的核心思想并不复杂，简称为 **PB-ROE框架**：

- **PB（市净率）**：估值指标，数值越小代表估值越低，对应[[价值投资]]维度
- **ROE（净资产收益率）增长率**：成长指标，数值越大代表盈利成长性越强，对应[[成长投资]]维度

**关键细节**：此处的ROE并非盈利因子本身，而是"ROE增长率"，属于成长因子。选股逻辑是：在PB估值中枢相对稳定的行业中，筛选ROE成长性强、偏向小市值、持仓高度分散的股票，并尽量规避周期股。最新持仓数据显示，前十大重仓股合计仅占15.27%，单只最高仅1.72%，印证了分散持仓的思路。

## 理论溯源：GARP策略

PB-ROE框架源于经典的[[GARP策略]]（Growth at a Reasonable Price，以合理价格买入成长股），是[[价值投资]]与[[成长投资]]两种思想的融合：

- **价值投资**：源于本杰明·格雷厄姆，代表人物包括[[巴菲特]]，关注低估值的好公司
- **成长投资**：关注营收、利润增速超行业的公司，代表如James Oelschlager
- **GARP策略**：彼得·林奇是该策略的代表，他在1977-1990年实现了29%的年化收益

GARP因同时兼顾价值与成长，风险适中、风险调整后收益高、逻辑清晰，深受[[量化投资]]者青睐。GARP的常用价值指标还有PE、PCF、PS等；常用成长指标还包括净利润增长率、销售净利率增长率等。

## 复现路径

### 因子组合方式的选择

复现采用第二种组合方式：先在全市场筛选PB最低的前N%股票，再按ROE成长因子从大到小排序，选出前M只。组合前需剔除次新股、ST股、净资产为负等异常股票。

### ROE成长因子的计算

采用多期复合环比计算，并对历史财报按时间衰减加权（越近的财报权重越大），公式示意：

```
T期复合ROE = (a×T-3期ROE + b×T-2期ROE + c×T-1期ROE + d×T期ROE) / (a+b+c+d)
T期ROE成长因子 = T期复合ROE - T-1期复合ROE
```

其中 a < b < c < d，体现"近大远小"的衰减加权。

## 回测结果

- **2010年至今约13年**：年化收益40.8%，验证了选股能力的有效性
- **2022年（大盘下跌近20%环境）**：取得31.8%正收益，体现抗跌性

## 复现与实盘的差异说明

1. 策略细节不同：王平在采访中强调PB-ROE只是核心，还会叠加其他辅助因子
2. 行业筛选：复现时同样需剔除高杠杆、周期不稳定的行业
3. 持仓差异：王平实盘极度分散，而个人复现持股数少且主动暴露[[市值风险]]，因此回测收益被放大

## 关键洞察

- 检验投资高手最有效的方法是"用历史数据回测其方法论"
- PB-ROE虽看似简单，但因子组合方式、ROE计算方式各有多种变体，复现工作量巨大
- 极简的[[多因子模型]]在A股长期有效，验证了[[基本面量化]]的可行性
- 持仓分散度是控制回撤的重要手段
