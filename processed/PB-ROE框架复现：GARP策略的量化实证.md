# PB-ROE框架复现：GARP策略的量化实证

## 核心结论
> 招商基金王平管理的招商量化精选采用PB-ROE框架，本质是经典GARP策略的典型实例——用PB衡量估值、ROE增长率衡量成长。个人宽客按此框架复现的策略在2010年至今回测中年化收益达40.8%，验证了该双因子组合的有效性，但回测表现优于实盘的原因在于持仓分散度与风险暴露的差异。

## 详细内容
## 背景与标的

区分"李逵"与"李鬼"的最好方法是把声称的交易方法放到历史数据中检验。原文以招商基金[[王平]]管理的[[招商量化精选]]A类（001917）为复现对象：王平2006年入行、2010年起担任基金经理，从业16年，见证公募量化基金发展全过程，目前管理规模超50亿元。该基金自2016年3月成立至原文写作时累计收益126.22%，同期沪深300仅30.03%，大幅跑赢96个百分点。

## PB-ROE框架

[[PB-ROE框架]]是[[GARP策略]]的典型实例，其核心思想是"在估值中枢（以PB衡量）相对稳定的行业中，筛选具有一定成长性（以ROE衡量）的股票"。需特别注意，此处的ROE实际指**ROE增长率**，即成长因子而非盈利因子本身。

- [[市净率PB]] = 股价/每股净资产，衡量估值
- [[净资产收益率ROE]]增长率 = 净利润/净资产的环比/同比变化，衡量成长
- 组合偏好小市值、高分散（持仓占比最高仅1.72%，前十大合计15.27%）
- 剔除周期股、高杠杆行业及净资产为负的异常样本

## GARP策略的思想脉络

[[GARP策略]]（Growth at a Reasonable Price）融合了[[价值投资]]与[[成长投资]]两大流派：

- **价值投资**：源于[[本杰明·格雷厄姆]]，寻找基本面好但价格低于内在价值的股票，代表人物[[巴菲特]]数十年年化收益超20%
- **成长投资**：关注营收、利润持续快于国家与行业增速的公司，代表人物[[詹姆斯·欧斯拉格]]
- **GARP融合**：典型代表为[[彼得·林奇]]，1977-1990年间实现29%平均年化收益

GARP策略同时兼顾估值与成长，风险适中、风险调整后收益高、逻辑清晰，特别受量化投资者青睐。PB-ROE只是GARP众多因子组合中的一种，其他常用估值因子还包括PE、PCF、PS，成长因子还包括净利润增速、销售净利率增速等。

## 复现实现

### 因子组合方式选择

常见的三种组合方式：

1. **打分加权法**：PB、ROE分别1-100分打分，按权重加总排序
2. **先估值后成长（本文采用）**：先按PB升序选前N%，再在池内按ROE降序选前M只
3. **先成长后估值**：先按ROE过滤，再用PB筛选，需对PB负值特殊处理

### ROE复合计算

采用多期时间衰减加权方式计算环比复合ROE，权重满足 a<b<c<d，越近的财报数据权重越大：

```
T-1期复合ROE = (a×T-4 + b×T-3 + c×T-2 + d×T-1) / (a+b+c+d)
T期复合ROE = (a×T-3 + b×T-2 + c×T-1 + d×T) / (a+b+c+d)
T期ROE成长因子 = T期复合ROE - T-1期复合ROE
```

预筛选环节剔除次新股、ST股、净资产为负等异常样本。

## 回测结果

- **2010年至今（近13年）**：年化收益 **40.8%**
- **当年大盘下跌近20%环境**：策略仍取得 **31.8%** 正收益

策略虽然简单，但在熊市中表现出色，验证了PB-ROE框架的有效性。

## 注意事项

1. 王平本人强调PB-ROE是核心但非全部，实际管理中仍辅以其他因子
2. PB-ROE框架隐含"估值中枢相对稳定"前提，需剔除高杠杆与周期不稳定行业
3. 回测表现显著优于实盘，原因有三：策略细节差异、回测与实盘摩擦、复现策略持股集中且主动暴露市值风险以博取高收益，而实盘通过极度分散控制风险
