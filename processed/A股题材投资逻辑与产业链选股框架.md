# A股题材投资逻辑与产业链选股框架

## 核心结论
> A股本质是题材驱动型市场，投资核心是炒预期——业绩兑现需要叠加概念与想象力，纯看业绩或K线难以盈利。有效路径是研读行业研报抓关键概念、顺产业链找正宗公司，重点关注产品技术差异而非公司规模或行业标签。国产替代优先级高于算力本身，英伟达链、特斯拉链、华为链是当下最强三大主线。

## 详细内容
## 投资观：预期驱动而非业绩驱动

A股牛短熊长叠加散户追涨杀跌的特性，决定了纯技术分析难以稳定盈利。**投资炒的是[[预期]]**——一句话概括："这个东西未来能卖出去，概念下的公司业绩在1年、3-5年内真的会涨"。完整闭环是：业绩兑现 → 预期落地 → 离场。这才是正儿八经的[[价值投资]]；拿五年十年的吃分红策略是另一种逻辑。

## 业绩 ≠ 股价的三个反直觉

- **业绩好 ≠ 股价涨**：[[贵州茅台]]业绩全A股顶尖，却不会大涨；只有业绩叠加概念、叠加想象力（新东西落地），股价才起飞。
- **大公司 ≠ 涨得多**：[[京东方A]]、[[鹏鼎控股]]、[[浪潮信息]]规模大但涨幅有限。
- **跟对概念才能爆发**：[[工业富联]]规模更大，因沾边[[英伟达链]]才能偶尔冲涨停。

## 方法论：从研报抓关键概念

最低成本获取官方信息的路径：在[[东方财富]]电脑版 → 研究报告 → 行业研报 → 选关注的行业（如半导体）→ 只看最近一周 → 通过标题锁定关键词，判断哪个题材更重要。消息太多反而吞噬判断，要**抓大放小、找关键点**。大胆假设，小心求证。

## 主流逻辑线拆解

### 英伟达链 = 算力核心

[[英伟达链]]是最强主线。正宗公司：[[胜宏科技]]、[[沪电股份]]、[[沃尔核材]]、[[工业富联]]、[[英维克]]、光模块三剑客（[[中际旭创]]、[[新易盛]]、[[天孚通信]]）。

- 沪电股份此前正宗，**现在已被胜宏替代**——原因在于产品技术差异：[[胜宏科技]]的[[HDI高密度互联版]]优于沪电，AI服务器刚需 + 资本开支高 + 业绩已确认，一路起飞。
- 光模块用于数据中心、服务器做数据收发，新易盛因业绩兑现而大涨，**热门题材 + 有预期的公司，业绩好才有用**。

### 特斯拉链

代表：[[拓普集团]]、[[三花智控]]。
- 三花智控电子膨胀阀全球第一，但白电预期低。
- 拓普集团单车ASP 3万，国内汽配无出其右，预期高 → 显著优于三花。

### 华为链

华为与[[赛力斯]]合作，2023下半年预期发酵，2024年业绩被验证（领先约半年），问界品牌已打出。其他标的：北汽、江淮、软通动力、润和软件、常山北明。**但华为链已炒过，资金喜新厌旧**。

### 雅鲁藏布江水电工程

去年墨脱水电站已有铺垫，近期开工引爆。逻辑线：**炸药 → 水泥 → 特高压**。
- 水泥：[[西藏天路]]、[[海螺水泥]]、[[华新水泥]]
- 关键在于弄清概念、找准关键公司。

### 端侧AI / AI眼镜

[[AI眼镜]]出货量可确认。芯片端：[[瑞芯微]]（rk3588 较好）、全志科技、晶晨股份。物联网概念模糊，无明确标的。

### 低空经济（eVTOL + 固态电池）

[[固态电池]]用锂量大，负极从石墨换成金属锂 → [[天齐锂业]]仍有空间。新能源车产业链与eVTOL、机器人高度重合：
- 共用：卧龙电驱、万丰奥威、潍柴动力
- 与机器人共用：双林股份、双环传动、拓普/三花

### 人形机器人

年初已炒过，**别接盘**。等特斯拉Optimus真正量产出货，抄底低估值公司：
- 灵巧手：[[鸣志电器]]、[[兆威机电]]（特斯拉链）
- 丝杠：北特科技
- 六维力矩传感器：柯力传感
- 四肢是重点：旋转执行器（肘关节）+ 线性执行器（大臂小臂、大腿小腿）
- 芯片特斯拉自研 → 不炒

## 公司分类：科技 vs 制造

同一行业内公司本质可能不同：
- **新能源车**：拓普/三花是科技+制造；中科创达/经纬恒润是纯科技；福耀玻璃偏制造+消费；德赛西威/伯特利是科技+制造。
- **半导体**：北方华创、中微公司、海光信息是科技类；长电科技、通富微电、华天科技偏制造。[[先进封装]]概念一般，封测是"苦力工"。长电科技像鹏鼎控股——规模大但技术含量没那么高。
- **PCB**：沪电、胜宏、兴森科技、深南电路是科技类；鹏鼎、东山精密偏制造业。

评判标准：**科技公司看产品技术，制造公司看成本控制**。

## 国产替代优先级

[[国产替代]]优先级 **>** 算力本身。算力 ≈ 英伟达链，国产算力是替代主线。

## 资料获取与筛选标准

免费资料足够，无需花钱买课：
- [[东方财富]]行业研报 + **深度** 限定词 → 按产业链梳理
- 公司层面：研报、年报、**[[投资者交流记录]]**（在[[巨潮网]]下载）
- 年报只看前10-30页即可
- 市值100亿以上、最好200亿+再深入研究——小公司公开资料有限，财报造假风险高（农林牧渔尤甚）
- 5000多家上市公司，可选择性放弃一些赛道
