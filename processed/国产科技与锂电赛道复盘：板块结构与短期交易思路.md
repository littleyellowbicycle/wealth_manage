# 国产科技与锂电赛道复盘：板块结构与短期交易思路

## 核心结论
> 短期主线集中在国产科技与锂电两条赛道，国产科技处于主升浪启动前的情绪发酵期（CPU、DeepSeek 催化），锂电则在电解液端出现启动信号、锂矿加速段预计落在五月。操作上月末季报风险需规避，建议 8-9 成锁仓配合 1-2 成滚动，下周一逢高兑现锂电、国产科技以底仓持有等待回踩确认。

## 详细内容
## 国产科技赛道结构

### 晶圆代工
[[中芯国际]] 是国产芯片的产能基础，也是 [[昇腾链]] 的核心代工厂。

### CPU
- 龙一：[[海光信息]]，CPU 与 GPU 双龙头
- 二线：龙芯、长城（政务向，炒作时一般归入第二梯队）
- 关联：曙光曾是海光大股东，去年重组失败，但主业不同

### 半导体设备
俗称"铲子股"，代表标的：中微、华创、拓荆、长川。其中长川与华创绑定较深，上一季度业绩表现亮眼。

### 封测
赛道相对明牌，仅三家厂商。龙一偏国产链，龙二与北美链绑定较深。

### 服务器
四家代表：浪潮、曙光、富联、紫光。浪潮近期强势，曙光与紫光相对更优。

### 数据中心 vs 算力租赁
[[数据中心]] 与 [[算力租赁]] 盈利模式相似但不相同，作者更看好算力租赁。数据中心需找与阿里、字节等头部大厂深度绑定的标的。

### 电源 / 液冷 / 光模块 / PCB
均属硬件配套设施。电源弱于液冷，液冷存在"误杀"但短期未必有行情：昇腾链上有两支（一家主板易走连板，另一家 20cm）。国产光模块以二线厂为主，PCB 则国产链与北美链共用。

### 昇腾链
- 设备/代工：中芯国际
- 芯片设计：寒武纪、海光、昇腾，其中 [[昇腾]] 是绝对龙头，与其他两家不在同一梯队
- 华为未上市，只能通过产业链相关个股（连接器、电源、液冷、服务器）参与

## 短期看法
周末 CPU 与 [[DeepSeek]] 消息发酵，英特尔周五夜盘大涨。

板块主升浪涨幅通常在 50%–100%，典型启动节奏：

> 周五大涨 → 周末发酵 → 周一开始分化 → 横盘震荡数日 → 情绪冷静后缓慢爬趋势

## 相关板块

### 航天
不看消息催化、只看量能信号，后续存在反包可能（具体时点不确定）。属于光通信退潮、国产算力未启动之间的真空期补涨。

### 算力租赁
逻辑硬，中线机会大；短期不看好。本质是用英伟达卡，筛选龙头看各家持卡数量。相较光通信的补涨板块。

情绪退潮期操作策略：
- 优先做龙头（光通信、PCB 材料），存在回流预期
- 或最低位（PCB 设备），可能挖掘补涨
- 尽量回避中位股（两头挨打）

### 光通信 / PCB
下周预计回流，作者已先行减仓。

## 新能源：锂电

### 顺位排序
> 锂矿 > 电解液 > 隔膜 ≈ 正负极材料 > 设备

### 时间窗口
锂矿加速段预计在五月。周五电解液出现启动信号，与 3.27 锂矿行情相似：涨停让散户激动 → 周末发酵 → 下周分化 → 高位震荡 → 等待二次启动。

## 下周预案
- 当前仓位：八成
- 节奏判断：周一反抽后继续跌，建仓点放在月末
- 锂电：周一继续卖出，等散户情绪冷静后再接回
- 国产科技：已打 30% 底仓，视开盘情况决定是否尾盘 T 出
- 仓位建议：下月 8-9 成锁仓 + 1-2 成滚动
- 关注 [[AI应用]]：底部个股量能异动，可能成为科技线炒作尾声切换方向
- 风险提示：月末季报需规避；北美链回流、国产科技临近爆发，可能被锂电行情"强行摁下"
