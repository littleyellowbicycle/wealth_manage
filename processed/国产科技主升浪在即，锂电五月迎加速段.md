# 国产科技主升浪在即，锂电五月迎加速段

## 核心结论
> 盘面聚焦 [[国产科技]] 与 [[新能源]] 两条主线：国产科技横盘蓄势后有望启动主升浪，[[昇腾链]] 作为绝对龙头辐射产业链补涨；锂电以锂矿为首，5月有望进入加速段。当前宜高仓位锁仓，在月末回调中分批建仓，并避免情绪退潮期的中位股。

## 详细内容
## 国产科技板块

### 板块细分

- **晶圆代工**：以 [[中芯国际]] 为核心标的。
- **CPU**：龙头为 [[海光信息]]，同时涉足 CPU 与 GPU；二线候补包括龙芯、长城（政务向，归为第二梯队）、曙光（海光大股东，去年重组失败，主业与海光不同）。
- **半导体设备**（铲子股）：[[中微公司]]、[[华创]]、[[拓荆]]、[[长川科技]]；其中长川与华链绑定较深，为去年三季度业绩明星。
- **封测**：赛道明牌，龙一偏国产，龙二与北美链绑定更深。
- **服务器**：浪潮、曙光、富联、紫光四选一，曙光与紫光更优。
- **数据中心**：与算力租赁盈利模式相似但不同，应优选绑定阿里、字节等头部大厂的标的。
- **硬件配套**（电源 / [[液冷]] / 光模块 / PCB）：电源弱于液冷；液冷短期被误杀但中长期看好；昇腾链中液冷个股包含主板连板标的与 20cm 弹性品种。
- **[[昇腾链]]**：华为未上市，只能通过产业链（连接器、电源、液冷、服务器）参与；昇腾、寒王、海光同属芯片设计，但昇腾是绝对龙头，与其他两个不在同一梯队。

### 短期看法

周末 CPU 与 deepseek 情绪发酵，英特尔美股夜盘大涨，踏空风险下可先建底仓。一个板块的 [[主升浪]] 涨幅通常在 50%-100%，启动后多有回踩确认。近期节奏几乎一致：周五大涨 → 周末发酵 → 周一分化 → 横盘震荡 → 情绪冷却后缓慢爬趋势。

### 相关板块

- **航天**：作为 [[光通信]] 退潮、国产算力正式启动前的真空期补涨主线；不看消息催化，只看量能信号，反包时点难判。自媒体对航天"新主线"或"诱多出货"的反复解读可反向参考。
- **[[算力租赁]]**：逻辑硬但短期不被看好，中线机会大；本质是英伟达卡资源博弈，按各家持卡量筛选龙头与杂毛；情绪退潮期只做龙头（光通信、PCB 材料）或最低位（PCB 设备），不做中位。
- **光通信 / PCB**：下周回流概率较大，先行离场。

## 新能源锂电板块

讨论范围仅限锂电。产业链上下游排序：锂矿 > 电解液 > 隔膜 ≈ 正负极材料 > 设备。[[锂矿]] 加速段预计在 5 月；电解液周五已现启动信号，节奏与 3.27 锂矿相似（涨停 → 发酵 → 分化 → 高位震荡 → 二次启动）。多多涨停是板块启动信号，与业绩无关。

## 下周预案

当前八成仓位。预计下周一为反抽后继续下跌，真正的建仓点在月末。操作要点：

- 周一继续卖出锂电，待散户情绪冷静后接回；
- 国产科技已建约 30% 底仓，若开盘不高则考虑尾盘买入并 T 出；
- 下月建议锁仓 8-9 成，1-2 成滚动操作（突发情况除外）；
- 关注 [[AI应用]] 底部量能异动，可能在科技线炒作尾声成为连板退潮方向；
- 北美链回流与国产科技爆发预期较强，但月末季报前宜保持谨慎；
- 继续下跌才是最佳场景，便于周三开仓；若大涨则保持冷静，不追高。
