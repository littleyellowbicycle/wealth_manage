# daily_stock_analysis 项目11策略与LLM量化框架解析

## 核心结论
> daily_stock_analysis 通过 Tushare 数据源、Deepseek 大模型与 ReAct Agent 模式，将散落的投资经验沉淀为 11 条可规则化、可回测的量化策略，核心价值在于让 LLM 充当信息汇总与决策叙事者而非直接操盘者。系统以「多源降级 + 前复权对齐」保证数据质量，以「策略路由 + 风险优先级」保证决策稳健，最终通过关键词回测闭环验证 LLM 输出与实际走势的偏离。

## 详细内容
## 项目概览

[daily_stock_analysis](https://github.com/ZhuLinsen/daily_stock_analysis) 是一个 31.8K star 的开源 A 股分析项目，定位为 [[LLM]] 辅助的 [[量化交易]] 框架。系统分为四层：数据层负责采集，计算层用 Python 计算技术指标，AI 层负责策略决策与叙事，最终输出结构化分析报告。

实验环境：数据源采用 [[Tushare]]，AI 模型使用 [[Deepseek]]，新闻源来自 anspire，回测标的为贵州茅台（600519.SH）。

## 数据层设计

数据层的核心原则是 **多源降级 + 断点续传 + 前复权对齐**，确保技术指标不因除权缺口产生假信号。

核心字段分三组：
- **日线标准化**：date、open/high/low/close、volume、amount、pct_chg
- **实时行情**：price、change_pct、volume_ratio、turnover_rate、pe_ratio/pb_ratio、change_60d
- **筹码分布（强烈推荐）**：profit_ratio、avg_cost、concentration_90、chip_status

趋势数据已预计算为结构化字段（trend_status、ma_alignment、bias_ma5、signal_score、risk_factors），供 Prompt 直接引用，避免 LLM 自行推算。

## Prompt 工程要点

项目提炼出四条核心 Prompt 设定：

1. **结论先行**：核心总结不超过 30 字，区分无持仓 / 有持仓建议，止损位必须给出具体数字。
2. **舆情强制规则**：每条信息必须带 YYYY-MM-DD 时间戳，超出新闻窗口或无法确认发布日期的一律忽略。
3. **数据缺失禁令**：N/A 数据严禁编造，必须明确说明「数据缺失，无法判断」。
4. **五问检查清单**：激活条件、入场风险回报、量能与筹码验证、消息面冲突、触发/止损/观察点。

## 11 个核心策略

策略按市况分类，匹配规则详见 [[策略路由]] 模块。

### 趋势类策略

**策略 1 · 默认多头趋势（bull_trend）**：MA5/MA10/MA20 多头排列 + MA20 斜率向上 + 不追高。评分上多头排列 +12，回踩均线企稳 +8，放量突破 +10，跌破 MA20 -12。心法：默认策略适用于大多数「正常」股票，不适合暴涨暴跌的妖股。

**策略 2 · 均线金叉（ma_golden_cross）**：MA5 上穿 MA10（或 MA10 上穿 MA20）+ 量能确认（金叉日成交量 > 5 日均量、量比 > 1.2）+ 乖离率 < 5%。心法：[[均线金叉]] 必须配合量能，无量金叉=假信号，盘整末端最可靠。

**策略 3 · 放量突破（volume_breakout）**：收盘站上 20 日高点或前期平台顶部 + 成交量 > 5 日均量 2 倍 + 强势收盘（位于振幅上方 30%）。心法：真突破需要「确认日」——次日收盘仍在突破位之上。

**策略 4 · 缩量回踩（shrink_pullback）**：上升趋势中回踩 MA5（误差 1% 内）或 MA10（误差 2% 内），回调期间成交量 < 5 日均量 70%，MA5 乖离率 < 2%。心法：趋势交易中性价比最高的入场点。

### 形态与反转类策略

**策略 5 · 箱体震荡（box_oscillation）**：识别至少 2-3 次触碰未跌破的支撑线与未突破的阻力线。距支撑 ≤5% 买入，距阻力 ≤5% 减仓，箱中观望。用「两日规则」（连续两日收盘突破 + 量能放大）过滤假突破。

**策略 6 · 底部放量（bottom_volume）**：20 日跌幅 > 15% 后，成交量 > 5 日均量 3 倍（量比 > 3.0）+ 当日收阳 + 前期极度缩量。仓位不超过 2-3 成，止损设近期低点下方。心法：底部放量属左侧交易，常有二次探底。

**策略 7 · 缠论（chan_theory）**：分型 → 笔 → 线段 → 中枢 → 背驰 的层级结构。一买为最后一个下跌中枢的底背驰，二买为离开中枢后回调不破中枢高点，三买为向上突破不回中枢。心法：先学 [[MACD背驰]] 单一信号，日线级底背驰胜率高。

**策略 8 · 波浪理论（wave_theory）**：5 浪推进 + 3 浪调整。硬约束：第 3 浪绝不是最短浪。最优买点是第 2 浪回调企稳（黄金坑），止损设第 1 浪起点。心法：数浪非常主观，应作框架而非教条。

### 热点与情绪类策略

**策略 9 · 龙头策略（dragon_head）**：所在板块近 5-10 日涨幅前列 + 个股率先涨停 + 换手率 > 5%、量比 > 1.5 + 板块级催化剂。龙头股乖离率可放宽至 7%，超过 10% 仍需谨慎。心法：买的是「板块溢价」而非个股阿尔法。

**策略 10 · 情绪周期（emotion_cycle）**：以换手率为情绪标尺（< 0.5% 冷淡、2-5% 活跃、> 10% 极度过热）。情绪底部特征：近 20 日换手率近一年低位 + 量能持续萎缩 < 60 日均量 50% + 负面新闻 + 股价贴近 MA20。心法：最接近「逆向投资」的策略。

**策略 11 · 一阳夹三阴（one_yang_three_yin）**：近 5 个交易日内，大阳线（实体 > 股价 2%）后接 3 根缩量阴线（最低价不破大阳开盘、量比 < 0.8），第 5 日阳线收盘突破大阳收盘价。本质是上升中继整理。

## Agent 模式与策略路由

系统采用 [[ReAct Agent]] 模式：LLM 规划 → 执行工具 → 结果返回 → LLM 思考 → 决定下一步，循环至信息充足后输出四阶段结论（数据 → 分析 → 决策 → 报告）。

[[策略路由]] 支持两种方式：
- **用户显式指定**：直接调用所选策略
- **自动路由**：根据 `ma_alignment` 与 `trend_score` 推断市况（bullish/bearish/sideways），匹配对应 `market_regimes`，多个匹配时按优先级取 Top1

## 持仓风险分析

风险模块完全基于规则而非 LLM，LLM 仅负责把规则结果翻译为口语化叙事。核心阈值：
- 单票集中度 35%
- 行业集中度 35%
- 最大回撤 15%
- 止损距离 10%（观察 8%）

## 回测闭环

回测模块通过关键词匹配从 LLM 的 `operation_advice` 字段提取意图（bullish / bearish / hold / wait），结合否定词与中性带宽判断方向正确性，并计算 `simulated_return_pct`。这使得 LLM 的输出可量化、可追踪、可迭代。

## 适用边界

> LLM 当前应作为量化交易的辅助工具——信息收集、汇总与决策参考。若期望 LLM 直接赚钱，仍需等待技术继续演进。
