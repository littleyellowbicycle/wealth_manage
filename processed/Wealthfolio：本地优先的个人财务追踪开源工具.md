# Wealthfolio：本地优先的个人财务追踪开源工具

## 核心结论
> Wealthfolio 是一款基于 Rust 构建的本地优先个人财务追踪工具，强调数据隐私与离线可控性，涵盖投资、净值、消费与模拟等核心场景。在隐私日益敏感的时代，它为注重资产配置与个人理财的用户提供了一个兼具美观与可定制性的开源替代方案。

## 详细内容
## 项目概览

[[Wealthfolio]] 是 GitHub 上的一款热门开源项目，已获得超过 8,113 Star。它使用 [[Rust]] 语言开发，定位为"美观、私密、本地优先"的个人财务追踪器。

## 核心功能

- **投资追踪**：记录股票、基金、ETF 等持仓，覆盖 [[资产配置]] 的日常管理与复盘需求。
- **净值计算**：自动汇总净资产，辅助 [[个人理财]] 全局视图。
- **消费记录**：跟踪日常支出，为预算与现金流分析提供基础数据。
- **投资模拟**：内建模拟器，可在历史或自定义场景下测试策略效果，某种程度上替代轻量级 [[回测]] 流程。

## 技术亮点

- **本地优先架构**：所有数据保存在用户本地，无需依赖云端服务，从根本上规避隐私泄露风险。
- **Rust 性能与安全**：借助 Rust 的内存安全与高性能特性，保证应用响应速度与稳定性。

## 适用人群

适合重视数据主权、追求开源可审计性、并希望统一管理 [[投资]]、消费与净值的个人用户；对量化或手动策略爱好者也是友好的轻量工具。

## 局限与考量

项目目前仍以个人/桌面端使用为主，缺少云同步与多端协作能力；对于机构级 [[风险控制]]、多账户并发处理能力有限，建议作为个人理财辅助，而非交易终端。
