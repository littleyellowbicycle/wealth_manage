# 有色化工板块配置计划与布林线交易纪律

## 核心结论
> 作者将有色/化工资源板块视为可贯穿牛市的镇仓石配置方向，主张分散布局锡、磷、钾、铝等周期个股，并以[[布林线]]为核心建立波段滚仓纪律：上轨减仓、中轨开仓、下轨加仓。当前板块情绪高涨且部分标的已翻倍，作者选择等待回踩中轨再行建仓，避免追高被套，并以规范化的交易纪律长期运行获取稳健收益曲线。

## 详细内容
## 板块判断与标的筛选

作者认为本轮行情中确定性最高、可贯穿牛市的是[[有色金属]]与[[化工]]板块的[[周期股]]。[[周期股]]一般不会急涨急跌，拉长均线来看一直沿趋势运行，适合作为账户的[[镇仓石]]做底仓配置。

由于去年金/银已大幅上涨、部分个股翻倍甚至 3–5 倍，作者回避高位品种，重点考虑以下四条资源主线：
- **锡**：[[锡业股份]]
- **磷**：[[云天化]]
- **钾**：[[亚钾国际]] + [[盐湖股份]]
- **铝**：[[宏创控股]]

## 交易纪律的核心原则

1. **趋势票必须规范化操作**：开仓、减仓、做 T、止盈都应遵循同一套纪律（如[[五日线]]/[[十日线]]或[[布林线]]），而非主观判断"跌够了"或"赚够了"。大跌加仓容易接飞刀，大涨清仓又容易卖飞，关键在于纪律的"一致性"，从[[大数定律]]角度看，只要纪律无原则性谬误，长期收益曲线必然稳健。

2. **优选[[布林线]]而非均线作为资源股纪律**：多数资源股沿[[布林线]]趋势上行，在市场风口不在时经常小涨小跌磨时间，若用[[十日线]]做纪律容易在横盘时被反复洗出；而[[布林线]]能更稳定地刻画运行区间，适合滚仓做 T。

4. **拒绝追高，保持耐心**：资本市场从来不缺机会，缺的是耐心。任何热门板块在主升后都会回到让人觉得"不可能回到"的位置，上涨时不要追高，大多数情况下都会有"倒车接人"的机会。踏空只是少赚，追高套牢才是真亏。

4. **[[布林线]]三档操作方案**：
   - [[布林线上轨]]：减仓做 T
   - [[布林线中轨]]：开仓 / 接回
   - [[布林线下轨]]：基本面无问题则加仓

## 仓位规划与建仓条件

| 规划标的 | 份额 | 建仓条件 |
| --- | --- | --- |
| [[锡业股份]] | 3 | 布林线中轨 |
| [[宏创控股]] | 1 | 布林线中轨 |
| [[亚钾国际]] | 1 | 布林线中轨 |
| [[盐湖股份]] | 1 | 布林线中轨 |
| [[云天化]] | 2 | 布林线中轨 |
| 补仓资金 | 2 | 布林线下轨 |

仓位选择的逻辑：
- **锡 vs 铝**：作者直接参考 Dang 老师的判断，锡优于铝，按 3:1 配置。
- **钾 vs 锂**：因已重仓[[锂矿]]、[[电解液]]、[[电池ETF]]，钾端优先选择海外标的[[亚钾国际]]以平衡含锂比例，[[盐湖股份]] 1:1 配置。
- **磷**：仅[[云天化]]一只代表性标的，给予 2 份权重。
- **补仓资金**：保留 2 份用于[[布林线下轨]]加仓。

## 风控纪律清单

1. 账户 1 的 4 成仓位用于资源股。
2. 沿[[布林线]]做波段滚仓，**卖飞的仓位不接回**，仅用剩余底仓继续做波段。
3. 浮盈 30cm 减半、50cm 本金清仓只留利润；出现以下任一信号则离场：
   - 破[[十日线]]3 日不收回
   - 单日放出天量
   - 筑顶滞涨
4. [[布林线下轨]]补原仓位 50%。

## 当前操作判断

近期有色/化工情绪高涨，作者认为不适合开仓，等待回调至[[布林线中轨]]再介入。即便资源股踏空，上半年机构票板块仍有大量机会，**被套对心态的伤害远大于踏空的损失**。
