# Claude Trading Skills：个人投资者 AI 交易工作流

## 核心结论
> Claude Trading Skills 是一套面向时间有限的个人投资者的开源 AI 交易工作流工具箱，核心不是代替用户买卖，而是将市场复盘、风险控制、交易计划、持仓管理和复盘学习标准化。项目以“核心 + 卫星”策略为主线，通过可组合的技能、工作流清单、决策闸门和交易记忆机制，把纪律置于收益追求之前；其输出不构成投资建议，也不保证未来收益。

## 详细内容
## 项目概览

`tradermonty/claude-trading-skills` 是一套基于 [[Claude Code]] 与 Claude Skills 构建的开源交易工作流工具箱，采用 MIT 许可证。材料记录时，该项目在 GitHub 上获得 3,964 个 Star，主要面向以长期投资、ETF 和股息股为核心，同时有纪律地开展波段交易的个人投资者。

项目不是自动交易系统、信号服务或收益承诺平台。它试图解决的核心问题是：时间有限的投资者如何通过固定流程完成市场判断、仓位规划、交易记录和事后复盘，并把个人经验沉淀为可重复改进的规则。

## 核心设计理念

- **AI 辅助而非代替决策**：[[人工智能]]用于整理信息、执行计算和检查流程，最终交易决定仍由投资者负责。
- **先控风险，再找机会**：市场状态评估、[[回撤熔断]]、[[仓位管理]]和[[交易前纪律检查]]构成候选交易的前置条件。
- **核心与卫星并行**：[[核心与卫星策略]]以长期持仓、ETF 和股息组合为核心，仅在市场条件允许时通过波段交易增加收益敞口。
- **保留人工决策闸门**：[[人工决策闸门]]用于阻止无计划、超额风险、报复性交易或在市场环境不允许时开仓。
- **从交易中学习**：[[交易日志]]记录投资逻辑、入场计划、仓位和结果，再通过[[交易复盘]]识别流程偏差并形成下一阶段规则。

## 五条主要工作流

| 使用目标 | 工作流 | 关键环节 | 数据与接口要求 |
|---|---|---|---|
| 15 分钟市场检查 | [[market-regime-daily]] | 市场广度、趋势参与度、敞口上限 | 基础路径无需付费 API |
| 每周核心组合复盘 | [[core-portfolio-weekly]] | 组合管理、股息审查、交易记忆 | 可使用 Alpaca；手工 CSV 为降级方案 |
| 条件式波段机会筛选 | [[swing-opportunity-daily]] | VCP 筛选、回撤熔断、技术分析、仓位计算、纪律闸门 | 筛选通常需要 FMP，风险与纪律环节可本地运行 |
| 记录每笔已平仓交易 | [[trade-memory-loop]] | 交易记忆、信号事后分析 | 手工路径无需 API |
| 月度绩效与规则调整 | [[monthly-performance-review]] | 交易记忆、复盘、策略研究 | 手工路径无需 API |

这些工作流由机器可读的 YAML 清单定义，明确技能顺序、决策条件和输出产物，比单纯调用单个技能更适合形成稳定的日常习惯。

## 技能覆盖范围

项目技能大致分为八个领域：

1. **市场状态**：市场广度、上涨趋势参与度、宏观环境、行业轮动、市场顶部与泡沫风险分析。
2. **核心组合**：持仓结构、资产配置、风险暴露、仓位再平衡及低估值成长股筛选。
3. **股息收入**：价值股息、股息增长回调、股息组合监控以及美国股息税务流程。
4. **波段机会**：VCP、CANSLIM、突破计划、主题识别和动量候选筛选。
5. **交易规划**：技术分析、股票仓位计算、期货仓位计算、回撤熔断与交易纪律检查。
6. **交易记忆**：投资论点追踪、信号复盘、交易绩效摘要和下一阶段行为规则。
7. **策略研究**：[[假设驱动策略研究]]、候选边缘发现、策略设计、样本外审视、回测与过拟合控制。
8. **高级卫星策略**：财报交易、期权策略、抛物线短线和其他小众研究流程。

## 零付费数据 API 起步路径

新用户可以先使用以下五项技能：

1. `market-breadth-analyzer`：读取公开 CSV，评估市场广度。
2. `uptrend-analyzer`：读取公开 CSV，判断上涨趋势参与度。
3. `position-sizer`：根据风险预算、止损距离等参数计算仓位，不进行外部数据读取。
4. `trader-memory-core`：使用本地 YAML 保存交易与投资论点。
5. `signal-postmortem`：结构化复盘交易结果和策略表现。

“无 API”不等于“无外部数据”：这些技能仍可能依赖公开 CSV、行情截图或本地文件，因此数据完整性、时间戳和口径仍需人工确认。

## 仓库结构与权威来源

- `skills/<skill-name>/`：各项技能的 `SKILL.md`、参考资料和辅助脚本。
- `skills-index.yaml`：全部技能元数据的[[技能索引]]，是技能说明的权威来源。
- `workflows/`：多技能工作流清单，是组合流程的权威来源，并可通过严格校验脚本检查。
- `skill-packages/`：可上传至 Claude Web Skills 页面的 `.skill` 压缩包。
- `skillsets/`：面向市场状态、核心组合、股息、波段、交易记忆和策略研究的安装组合。
- `docs/` 与 `scripts/`：文档、目录生成器、校验器和打包工具。

当 README、文档与索引之间出现不一致时，应以 `skills-index.yaml` 和 `workflows/*.yaml` 为准。这一设计降低了提示词、文档与自动化流程之间的漂移风险。

## 安装与运行

### Claude Web

从最新 GitHub Release 下载所需 `.skill` 文件和 `SHA256SUMS`，校验哈希后，在账户设置中启用代码执行与文件创建，再通过 **Customize > Skills** 上传并启用。不同账户类型的权限与可用性可能变化，应以 Anthropic 官方说明为准。

### Claude Code

克隆仓库后，可将技能目录复制到个人级 `~/.claude/skills/`，或项目级 `.claude/skills/`。若要上传到 Web 应用，可先修改源目录，再运行 `python3 scripts/package_skills.py --skill <skill-name>` 重新构建技能包。

共享项目环境主要支持 Python 3.11–3.13，并覆盖 Linux、Windows 和 macOS；独立打包技能保留 Python 3.9 源码兼容下限。其他组合是否可靠，应以兼容性矩阵和持续集成结果为准。

## 风险边界与使用限制

- 项目仅用于教育、研究和流程改进，不构成投资建议、税务意见、法律意见或经纪交易服务。
- [[交易风险]]始终存在，包括本金亏损；历史表现、回测、选股结果和 AI 分析均不能保证未来结果。
- 交易决策、仓位规模、税务与监管合规以及券商操作均由用户负责。
- 项目不适合完全自动交易、信号外包或超短线剥头皮，[[人工决策闸门]]仍是流程核心。
- AI 输出可能受缺失数据、错误输入和模型判断影响，不应绕过独立核验。

## 价值判断

该项目最重要的贡献不是提供“更准的买卖信号”，而是把[[交易流程标准化]]、风险前置和持续复盘组合成可共享的[[个人交易系统]]。对个人投资者而言，其采用价值取决于是否愿意持续维护数据、检查清单和交易记忆，而不是仅安装更多技能。
