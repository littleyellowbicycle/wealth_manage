# 用OpenClaw搭建个人股票分析Agent

## 核心结论
> 借助[[OpenClaw]] Agent框架与[[Finnhub]]实时行情API，普通个人可在10分钟内零代码搭建专属股票筛选系统，每天自动输出盘前选股报告。核心价值不在于选出的5支股票，而在于将人工盯盘彻底升级为可调度、可持续学习的[[Agent工作流]]，让个人投资者获得接近机构级的数据与系统能力。

## 详细内容
## 背景与定位

过去几年，[[量化交易]]机构和高频基金依靠**数据优势**与**系统优势**形成壁垒。如今借助[[OpenClaw]]这类Agent框架，配合实时行情API和自动化调度能力，普通个人也能在极短时间内搭建专属的[[股票筛选]]系统。

> 所需条件：一台服务器 + 一个API Key + 约10分钟时间，无需写复杂代码，也无需专业量化背景。

## 核心流程

### 1. 配置盘前交易Agent

在OpenClaw中执行 `openclaw tui` 进入对话框，通过自然语言指令配置一个股票日报分析Agent，并设置人设prompt。该Agent会被命名为 Marcus，负责盘前选股。

### 2. 接入实时数据与浏览器能力

- 注册 [finnhub.io](http://finnhub.io) 免费账号，获取API Key，用于获取实时行情数据。
- 在OpenClaw中通过对话指令，将Finnhub的常用数据能力与浏览器搜索能力一并接入 stock-daily agent。
- 测试调用是否成功，若有数据返回则说明接入完成。

### 3. 自动输出盘前报告

Agent会在固定时间自动抓取实时行情、结合新闻与技术面，输出一份盘前选股报告，最终筛选出5支潜力股。

## 闭环价值

整个流程形成完整闭环：

服务器部署 → Agent人设配置 → 实时数据接入 → QQ机器人打通 → 自动生成盘前报告。

这套系统具备以下特征：
- **定时输出**：每天固定时间生成报告；
- **自动抓取**：自动拉取实时行情数据；
- **多维分析**：结合新闻面与技术面综合判断；
- **持续学习**：可不断学习用户的偏好。

因此它已不再是简单的聊天机器人，而是一个真正属于个人的**交易助理系统**。

## 关键概念

- [[OpenClaw]]：Agent开发框架，支持TUI交互与自然语言配置
- [[Finnhub]]：提供免费层级API的实时股票数据服务
- [[Agent工作流]]：将传统人工操作转化为可调度、可复用的自动化流程
- [[盘前报告]]：交易日前生成、辅助当日决策的选股分析文档
