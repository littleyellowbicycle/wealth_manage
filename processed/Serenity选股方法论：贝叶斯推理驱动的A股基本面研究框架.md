# Serenity选股方法论：贝叶斯推理驱动的A股基本面研究框架

## 核心结论
> Serenity是一套基于贝叶斯推理的A股基本面研究框架，核心思想是将新闻事件转化为对未来3-5年收入CAGR的概率更新，而非简单的利好/利空二元判断。框架由Serenity Alpha（新闻→Alpha假设）和贝叶斯内在增长估值（先验→后验→市场隐含增长对比）两个互补工具组成，配合Hermes Agent等AI工具可在本地实盘运行，已有一周跑赢大盘的验证记录。

## 框架概览

Serenity本质上是一套**概率化的投资分析框架**，包含两个互补工具：

1. **[[Serenity Alpha]]**：将市场新闻转化为可验证的Alpha假设
2. **[[贝叶斯内在增长估值]]**：用概率更新评估公司真实增长速度与市场定价的偏离

两者结合可以覆盖从事件触发（新闻/公告）到单股估值判断再到组合横截面比较的完整决策链。

## 设计理念

传统投资分析容易陷入"利好/利空"的二元判断。Serenity的核心思想是：

> **不要把新闻简单归类为利好或利空。把每个数据点转化为对未来3-5年收入CAGR的概率更新。**

这一思路借鉴了[[贝叶斯推理]]的核心方法——先用先验概率描述对一家公司增长前景的判断，再用新信息（新闻、财报、公告）逐步修正后验概率，最终得到一个**加权的内在增长速度估计**。

## 一、Serenity Alpha：新闻 → Alpha假设

将新闻/事件/公告转化为可验证的投资假设，核心流程为：

```
新闻 → 已观察到的需求变化 → 财务传导路径 → 小市值弹性 → 验证路径
```

输出结构化的Alpha报告，包含：

- **结论先行**：点名最值得验证的公司
- **需求变化分析**：区分"叙事"与"已发生的需求变化"
- **财务翻译**：需求如何进入利润表
- **小市值高弹性标的筛选**：在小盘股中寻找弹性最大的标的
- **市场误分类测试**：检验当前定价是否反映了该信息
- **验证指标**：1-4季度内可验证的关键变量
- **Alpha强度评分**：综合打分

## 二、贝叶斯内在增长估值

用概率思维评估公司真实增长速度，与市场定价对比：

- **6个增长假设**：从H0（衰退<0%）到H5（平台级扩张>50%），覆盖极端悲观到极端乐观的全部情形
- **先验 → 新信息 → 后验**：每条信息都更新各假设的概率分布
- **加权内在增长速度**：根据后验概率估算加权[[CAGR]]
- **市场隐含增长速度**：反推当前股价/市值已隐含的增长率
- **估值状态判断**：低估 / 合理 / 高估但可交易 / 泡沫化

## 触发场景

| 场景 | 使用方法 |
| --- | --- |
| 分享一条新闻/公告 | Serenity Alpha — 分析是否产生Alpha机会 |
| 问某公司值不值得买 | 贝叶斯估值 — 内在增长 vs 市场定价 |
| 问新闻对持仓的影响 | Alpha + 贝叶斯结合 |
| 连续分析多只同主题股票 | 独立分析 + 横截面比较 |

## 工具链与运行环境

要完整运行该skill，需要安装一个[[Hermes Agent]]或Openclaw，将skill文件夹路径告诉Agent让其自动学习，随后即可通过自然语言对话触发分析。

文件结构包括：

- `SKILL.md` — 主框架完整方法论与输出模板
- `references/data-gathering-workflow.md` — 数据采集命令大全
- `references/serenity-alpha-original.md` — Alpha框架原文
- `references/bayesian-valuation-original.md` — 贝叶斯估值框架原文
- `references/4-source-extraction-flow.md` — 四源数据采集实战流程

## 数据源整合

框架整合了多个免费数据接口（具体命令见workflow文档）：

- **实时行情** → Sina Finance API（curl，无需浏览器）
- **估值/行业排名** → 东方财富push2 API
- **财务时间序列** → 同花顺F10财务页
- **公告/减持/龙虎榜** → 东方财富公告页
- **新闻** → 新浪财经首页
- **K线分析** → Sina 30分钟/5分钟API
- **实时资金流向** → 东方财富行情页底部

## 风控与注意事项

- 所有输出均为研究假设，**不构成投资建议**
- 重点关注**内部人减持信号**：股票暴涨期间控股股东同步减持是最强烈的警示
- 重点关注**股东户数变化**：筹码分散是中期方向的重要先行指标
- 数据交叉验证：Sina实时价 vs 东方财富估值，避免单一来源错误
