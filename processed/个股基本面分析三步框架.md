# 个股基本面分析三步框架

## 核心结论
> 个股研究可收敛为三个核心问题：靠什么赚钱、赚钱能力如何、未来如何赚钱。盈利质量须以 [[净资产收益率]] 和 [[杜邦分析]] 切入，并通过「护城河四连问」定位真实竞争壁垒；成长性要看营收增速与自由现金流，偿债性以资产负债率、流动比率、速动比率兜底。最终结合 [[波特五力模型]] 判断行业天花板与竞争格局，再以市盈率等工具完成 [[估值]]。

## 详细内容
## 一、分析框架总览

研究一家上市公司，本质上只需回答三个问题：

1. **公司靠什么赚钱？**——主营业务定位与 [[商业模式]] 拆解
2. **赚钱能力如何？**——盈利能力、护城河、运营效率、成长性、偿债能力
3. **未来如何赚钱？**——市场空间、竞争格局、估值

## 二、公司靠什么赚钱

### 1. 主营业务

生意分三六九等。自来水、电力这类天然垄断业务可以「躺着赚钱」；而高度同质化、靠价格战存活的行业则生存艰难。研究时需明确公司是卖商品还是卖服务、收入来源是否集中，例如格力电器主营空调，兼营手机等小业务。

### 2. 商业模式

同样的生意因商业逻辑不同会走向迥异的结局：

- **轻资产 vs 重资产**：淘宝提供平台收广告费与沉淀资金（轻资产），京东自营建仓建物流（重资产）
- **收钱节奏**：贵州茅台先收钱后发货，体现为高额预收账款；东方园林先发货后收款，体现为大量应收账款

商业模式决定了 [[资产负债表]] 结构与现金流质量。

## 三、赚钱能力如何

### 1. 盈利能力：[[净资产收益率]]（ROE）

好公司与差公司是比出来的，ROE 是衡量赚钱能力的核心指标（高杠杆行业需慎用）。例如格力电器 ROE 常年在 30% 左右，远超同行。

### 2. 护城河分析：「四连问」法则

利用 [[杜邦分析]] 公式 `ROE = 净利润率 × 总资产周转率 × 杠杆率`，逐层追问：

- **一问**：为什么 ROE 高于同行？——定位是净利润率、周转率还是杠杆率驱动
- **二问**：为什么该因子高于同行？——例如净利润率高，是毛利率高还是三费占比低
- **三问**：为什么毛利率高/费用率低？——是定价权、成本优势还是管理效率
- **四问**：既然有效，竞争对手为何不模仿？——回答不出则说明护城河不真实

以贵州茅台为例：高端品牌形成定价权 → 高毛利率；同时供不应求无需打广告 → 低销售费用率，竞争对手无法模仿，构成 [[品牌护城河]]。

### 3. 运营能力

再好的护城河也需管理层执行，运营效率关注三件事：东西卖得快不快（[[存货周转率]]）、钱能不能收回（[[应收账款周转率]]）、资产是否高效利用（[[总资产周转率]]）。例如包子铺当天包子当天卖完、一手交钱一手交货即为理想状态。

### 4. 成长能力

公司类似个人生命周期：

- **营业收入增长率 > 10%**：成长期
- **5%～10%**：稳定期，临近衰退
- **< 5%**：衰退期，需新产品接力

更关键的是 **经营活动现金流** 与 **[[自由现金流]]**：`自由现金流 = 经营活动现金流 - 资本开支`，这才是公司真正的「造血能力」。警惕「现金流下滑但利润上升」的虚胖现象。

### 5. 偿债能力

盈利能力再强，若债务压顶也会瞬间崩塌：

- **资产负债率 = 总负债 / 总资产**：越低越好，非金融行业 > 50% 即危险
- **流动比率 = 流动资产 / 流动负债**：≈ 2 为佳，过高说明资产闲置
- **速动比率 = 速动资产 / 流动负债**：≈ 1 为佳，剔除存货、预付账款等难变现项

## 四、未来如何赚钱

### 1. 市场空间与天花板

行业即「杯子」，决定了公司体量的上限。判断距离天花板多远：

- **已触顶**：存量博弈（如煤炭）
- **打破旧天花板**：依赖技术创新或模式创新（如美团从团购扩展至外卖、旅宿）
- **天花板未形成**：新兴行业（如 [[新能源汽车]]、[[物联网]]、[[人工智能]]）

分析路径：确定行业 → 判断供求 → 公司行业地位 → 公司现状 → 估算天花板。

### 2. 竞争格局：[[波特五力模型]]

蛋糕大小之外，还要看分蛋糕的人有多少。波特认为五种力量决定行业竞争烈度：

1. 供应商议价能力
2. 购买者议价能力
3. 潜在进入者威胁
4. 替代品威胁
5. 同业竞争强度

格局越接近「一人独饮」（垄断），盈利越稳定；「百家争鸣」（充分竞争）则利润微薄。

## 五、定性因素与估值

定性层面需关注管理层言行一致性、战略专注度、股权与组织结构、企业文化、研发投入等，这些依赖长期积累。

最后一步才是 [[估值]]。常用工具包括 [[市盈率]]（PE）、[[市净率]]（PB）、[[市销率]]（PS）、自由现金流折现、PEG、清算估值法等。估值准确度取决于前文分析的深度，不存在跳过基本面直接套公式的捷径。

## 六、心法

正如 [[降龙十八掌]] 只有十八招却威力无穷，分析框架的威力不在招式多寡，而在「**专注**」二字——把每一招练到极致，方能在竞争中胜出。
